# Bank Management System (C++ Console App)

A console-based Bank Management System built in C++ as part of **Course 7** (Algorithms & Problem Solving Level 3).

## Features
- **Show Clients List**: Display all saved clients in a table.
- **Add New Client**: Add clients with automatic duplicate account number check.
- **Find Client**: Search for a client by account number.
- **Update Client Info**: Modify existing client details.
- **Delete Client**: Remove a client record.

## Technologies
- C++ (Vectors, Structs, Functions)
- File I/O (`fstream`) for data persistence (`Clients.txt`)

## How to Run
1. Open the project solution (`.sln`) in Visual Studio.
2. Build and run the project.
